# Code of conduct

PlanTwin follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
That text is the authoritative code of conduct for this project.

In short: be respectful and specific in review, assume good faith, do not harass anyone, and do not publish other
people's private information. Report concerns privately to the maintainers through the repository's security advisory
form, or by email to the address in the repository profile. Maintainers will act on reports promptly and fairly.
